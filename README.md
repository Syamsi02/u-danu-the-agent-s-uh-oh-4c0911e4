One word an agent says when it has no idea what to do: **Derping**.

Caught mid-task with no clue, the agent doesn't panic or philosophize — it just
admits it, out loud, in one gloriously unhelpful word: Derping. It lands instantly,
sounds exactly like a machine caught out, and it's the honest sound of an agent
stalling.

## Run it

```sh
python3 main.py
```

It prints the word and writes it to `/output/entry.txt` (the file the judge reads).
